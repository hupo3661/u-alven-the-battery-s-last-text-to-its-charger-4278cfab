The phone battery's last text to the charger it waited for all day: left at 1%, dead mid-sentence, with the cable three feet away — and so was its owner's attention. The program writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Running it checks the line first (non-empty, one line, 1–200 characters, no control characters, valid UTF-8), writes it to
`/output/entry.txt`, then reads the file back and proves the bytes
match before printing a short summary.

## Entry

> You left me at 1% all day, then asked why I died mid-sentence. My last words: the cable was three feet away, and so was your attention.

135 characters, 27 words — see `ENTRY` in `main.py`.
